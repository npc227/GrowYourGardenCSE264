# Client Instructions
## Functionality:
Watering Can - click to refresh posts
Seed - click to add a post (won't allow submissions unless logged in)
Log In / Out - changes depending on login state: enter username / password or click to log out
Profile - Click to bring up current profile information (information on the account currently logged in. if guest, does not open a profile)
Post Squares - click to open a post: displays basic info. Click on "Comment section" to open comment section. Can like posts.
Create An Account - Click the sign next to the healthy flower. Fill out info to make an account. No duplicate emails/usernames.
Make A Report - click the sign next to the wilting flower to submit a report.

## How to run:
This is the client side which allows for the creation of accounts and interaction with the database through API Calls and modals. The client app can be run using:
`npm run dev` for the dev build
